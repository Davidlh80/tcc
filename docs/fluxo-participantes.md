# Fluxo dos Participantes

## Etapas

1. Ler os requisitos gerais e específicos.
2. Criar uma branch para desenvolvimento.
3. Implementar o template Terraform.
4. Registrar início, término e pausas.
5. Abrir Pull Request.
6. Aguardar as validações automatizadas.

## Padrão de branch

```text
manual/<participante>/<recurso>
```

Exemplos: `manual/p01/s3`, `manual/p01/iam` e `manual/p01/security-group`.

## Formulário

Registrar recurso, horários, pausas, dificuldade percebida e experiência prévia com Terraform/IaC.
