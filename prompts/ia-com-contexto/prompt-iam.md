# Prompt IAM - IA com contexto

Crie um template Terraform para uma policy AWS IAM, considerando `contexto/contexto-organizacional.md`.

Inclua `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf` e `README.md`. Siga o menor privilégio, restrinja ações e recursos, evite wildcard amplo, use nomenclatura e tags padronizadas quando suportado e declare nome, ARN e ID como outputs.
