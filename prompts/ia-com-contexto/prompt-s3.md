# Prompt S3 - IA com contexto

Crie um template Terraform para provisionar um bucket Amazon S3, considerando também `contexto/contexto-organizacional.md`.

O template deve conter `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf` e `README.md`. Deve bloquear acesso público, habilitar criptografia, permitir versionamento configurável, declarar outputs e utilizar variáveis. Siga os padrões de nomenclatura, tags, segurança e organização definidos no contexto.
