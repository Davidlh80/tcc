# Prompt IAM - IA sem contexto

Crie um template Terraform para uma policy AWS IAM.

O template deve conter `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf` e `README.md`. Crie uma policy seguindo o menor privilégio, evitando permissões administrativas e wildcard amplo. Use variáveis para nome, ambiente, ações e recursos permitidos e declare nome, ARN e ID como outputs.
