# Prompt S3 - IA sem contexto

Crie um template Terraform para provisionar um bucket Amazon S3.

O template deve conter `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf` e `README.md`.

Requisitos: criar o bucket, bloquear acesso público, habilitar criptografia, permitir versionamento configurável, declarar outputs relevantes e utilizar variáveis configuráveis.
