# Prompt Security Group - IA sem contexto

Crie um template Terraform para um AWS Security Group.

O template deve conter `main.tf`, `variables.tf`, `outputs.tf`, `versions.tf` e `README.md`. Permita configurar VPC, regras de entrada e saída, portas e CIDRs. Evite abertura irrestrita desnecessária e declare ID, ARN e nome como outputs.
