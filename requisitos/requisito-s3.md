# Requisitos do Template S3

O template deve criar um bucket Amazon S3 com configurações básicas de segurança e governança.

## Obrigatórios

- Criar um bucket S3;
- bloquear acesso público;
- habilitar criptografia;
- permitir versionamento configurável;
- aplicar tags obrigatórias;
- declarar outputs relevantes.

## Variáveis esperadas

Nome do bucket, ambiente, habilitação de versionamento e tags adicionais, se aplicável.

## Outputs esperados

Nome, ARN e ID do bucket.
